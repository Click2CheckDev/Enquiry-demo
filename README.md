# Crystal Hub — demo

A clickable walkthrough of Crystal Specialist Finance's Property Finance Enquiry
run through the Click2Check hub: Crystal's front page, the blank enquiry form,
the customer's credit report and Open Banking (download as PDF or view as HTML),
and the form filled in from them with the source of every answer.

It sits alongside the [HMRC demo](https://click2checkdev.github.io/HMRC-demo/)
and the [Affordability demo](https://click2checkdev.github.io/Affordability-demo/)
and uses the same hub styling.

**Live: https://click2checkdev.github.io/Crystal-demo/**

Fictional data, no backend: nothing is requested from any bureau or bank.
One self-contained `index.html`; the PDFs are made in the browser.
